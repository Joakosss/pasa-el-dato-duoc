# Historias de Usuario — Usuario/Cuenta

Carpeta para historias centradas en la **cuenta** del usuario (datos de autenticación y gestión de cuenta), separadas de:

- **auth/**: inicio/cierre de sesión, refresh, rol durante sesión.
- **perfil/**: datos de perfil (teléfono, sede, etc.) cubiertos por HU-PERF-01/02.

Convención sugerida:
- `HU-PERF-XX.md` para “mi cuenta” (read/update/delete), manteniendo consistencia de prefijos ya usados en el repositorio.
